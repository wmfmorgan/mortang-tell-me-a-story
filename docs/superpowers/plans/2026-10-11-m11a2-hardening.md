**Goal:** Close the Trinity findings on the shipped origin-story access model without changing who can contribute, without new policies, and without reopening M11a.

**Architecture:** One new migration after `20261011150000_origin_stories.sql`. Whitelist BEFORE UPDATE guards on comments, perspectives, and photos. `set_family_origin` checks a deleted parent before the story lookup, then returns one `NOT_FOUND`. The six M11a security-definer functions move to `search_path = ''`. A BEFORE INSERT trigger caps a story at 20 `photos` rows and locks the story with `for no key update`. The reader picks people by membership of the story's family, and shows photo Remove only when the caller can still contribute and is the uploader or the story author.

**Tech stack:** Flutter 3.x, existing `albumTheme()`, PostgREST, pgTAP. Local Supabase only. `supabase migration up --local`. Never `db reset` or `migration down`.

- [ ] **Step 2.** Replace `set_family_origin`. Order is the gate, then the parent, then one story lookup. Do not re-check the parent after the lookup. Do not touch grants.

```sql
create or replace function public.set_family_origin(
  p_family_id uuid,
  p_story_id uuid
)
returns void
language plpgsql
security definer
set search_path = ''
as $$
declare
  fam public.families;
  parent public.families;
  story public.stories;
  expected uuid;
begin
  if (select auth.uid()) is null
     or not exists (
       select 1
       from public.families f
       where f.id = p_family_id
         and f.deleted_at is null
     )
     or not (
       public.is_family_owner(p_family_id)
       or public.is_family_co_owner(p_family_id)
     ) then
    raise exception 'FORBIDDEN';
  end if;

  select * into fam from public.families where id = p_family_id;
  if fam.parent_family_id is not null then
    select * into parent from public.families where id = fam.parent_family_id;
    if not found or parent.deleted_at is not null then
      raise exception 'VALIDATION: parent family is deleted';
    end if;
  end if;

  expected := coalesce(fam.parent_family_id, fam.id);
  select * into story from public.stories where id = p_story_id;
  if not found
     or story.status is distinct from 'published'
     or story.family_id is distinct from expected then
    raise exception 'NOT_FOUND';
  end if;

  perform pg_catalog.set_config('app.family_origin', 'on', true);
  update public.families
  set origin_story_id = p_story_id
  where id = p_family_id;
  perform pg_catalog.set_config('app.family_origin', 'off', true);
end;
$$;
```
