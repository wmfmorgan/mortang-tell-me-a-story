## Data

Migration `supabase/migrations/20261005000001_profile_avatar.sql` matches Design Doc. No column doc doesn't name.

```sql
alter table public.profiles
  add column avatar_path text;

alter table public.profiles
  add constraint profiles_avatar_path_own
  check (
    avatar_path is null
    or avatar_path = (id::text || '/avatar.jpg')
  );
```

Private bucket `avatars`. `file_size_limit` 2097152. MIME `image/jpeg` only. One object, `{auth.uid()}/avatar.jpg`. SELECT, INSERT, UPDATE, DELETE for `authenticated` require `bucket_id = 'avatars'` and `name = auth.uid()::text || '/avatar.jpg'`. Upload upserts. No `story-photos`. No public URL.

Co-member SELECT of `profiles` already returns row → returns `avatar_path`. No other screen paints it. Co-member no get file.

Email trigger, same migration. Insert bootstrap stays `handle_new_user()`.

```sql
create or replace function public.sync_profile_email()
returns trigger
language plpgsql
security definer
set search_path = public
as $$
begin
  update public.profiles
    set email = new.email,
        updated_at = now()
    where id = new.id;
  return new;
end;
$$;

create trigger on_auth_user_email_updated
  after update of email on auth.users
  for each row
  when (new.email is distinct from old.email)
  execute function public.sync_profile_email();
```

Reuse `compressStoryPhoto` with `maxEdge: 512`, `quality: 80`. File existing decoder can't read → no upload, use SnackBar above. No HEIC package.
